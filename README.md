# Cloud 6

ACC 2기 해커톤 Cloud 6팀 프로젝트 레포지토리입니다.

사회초년생 대상으로 랜덤 채팅을 하며 예능 영상을 볼 수 있는 서비스를 기획했습니다.

## 기술 스택
### AWS 서비스
- Fargate
- RDS
- DynamoDB
- Elastic Cache
- Cloud Watch
- Application Load Balancer

### 서버 개발
- Spring Boot
- JPA
- Redis
- WebSocket
- MySQL
